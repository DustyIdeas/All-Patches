Dusty's World Border v1.3.0.md
# **Patch Notes** -  3/26/25 @ 1:30 AM PT

---

## **Updates**  
- **Updated for Minecraft Bedrock version `1.21.70+`.**  
  *Note:* This version is not compatible with earlier releases. 

---  

## **Added**  
### **Border Color Customization**  
- **New Custom Command**: You can now change the color of the world border using the command:  
  `/tag @r add _br_color_<COLOR>`  
  - **Available Colors:** White, Black, Brown, Pink, Orange, Green, Blue, Yellow, Purple, Red.  

- **GUI Integration**: A new option in the settings menu allows you to change the border color without using commands.

- **Border Color Display**: The main menu now displays the current border color, making it easier to track active settings.

---

## **Improved**  
- **Script now runs as Admin**, ensuring it works on all worlds, servers, and realms. Fixes previous permission issues.
