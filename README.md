# DustyIdeas Minecraft Bedrock Tools

This repository houses various gameplay tweaks and quality-of-life improvements for Minecraft Bedrock Edition. These are personal projects I've developed during my modding experiments, shared here for community use.

## Available Releases

- **Release #1**  
  [Health Display for Players & Entities](https://github.com/DustyIdeas/All-Patches/releases/tag/1)  
  Track health values for all entities in real-time

- **Release #2**  
  [World Border Addon](https://github.com/DustyIdeas/All-Patches/releases/tag/2)  
  Configure custom world boundaries with visual indicators

- **Release #3**  
  [Player Attributes Monitor](https://github.com/DustyIdeas/All-Patches/releases/tag/3)  
  Detailed display of player stats and status effects
